# Pharmacy Sales System 

## Project Description
The Pharmacy Sales System is a simple Python project that tracks medicine sales. It calculates total sales, applies discounts, updates quantities sold, and validates sales.

## Features
- Store medicine name, price, and quantity sold.
- Calculate the total sale amount.
- Apply discounts without changing the original price.
- Update the quantity sold.
- Check whether a sale is valid.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Example
The system records a sale of 50 units of Paracetamol at KSh 20 per unit.

- Initial total: KSh 1,000
- Total after a 10% discount: KSh 900
- Updated quantity: 60 units
- Updated total: KSh 1,200
- Sale status: Valid sale

Install Python.

Clone or download this repository.
